# Anbumathi Chezhian | Portfolio

Personal portfolio website for **Anbumathi Chezhian**, an Electronics & IoT Project Developer passionate about creating smart, connected systems that solve real-world problems.

**Live site:** https://v0-anbumathi-chezhian-2203.vercel.app

## About

A single-page portfolio featuring a cyber/IoT neon aesthetic. Sections include:

- **Hero** — introduction and call to action
- **About** — background and focus areas
- **Skills** — electronics, IoT, and development capabilities
- **Projects** — featured work and case studies
- **Certifications** — credentials and achievements
- **Contact** — get-in-touch form

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript / React
- **Styling:** CSS with custom neon/cyber theme
- **Fonts:** Rajdhani, Share Tech Mono, Inter (via `next/font`)
- **Deployment:** Vercel
